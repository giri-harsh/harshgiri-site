Harsh designed a multi-tenant agentic RAG API on FastAPI and LangGraph with a self-correcting retrieve, grade and rewrite cycle, Postgres-backed checkpointing, Portkey LLM fallback and a fail-closed NeMo Guardrails (Colang) layer that screens prompt-injection and jailbreak attempts. Each request carries a tenant-isolated API key, Redis holds rate limits and caches, and a semantic answer cache can answer first-turn questions before any retrieval. Retrieval is hybrid in Qdrant: HNSW dense embeddings plus sparse BM25, fused with RRF, then reranked by an ONNX cross-encoder. On a limited benchmark of 60 labeled questions it reached 100% Hit@1 and 1.00 MRR at about 17 ms search latency. In a Locust load test with a simulated LLM backend, 50 tenants and 500 concurrent users, throughput rose from 15.4 to 128.6 RPS (+735%) and p95 latency fell from 55 s to 4.9 s (-91%) at 0% errors. In a Redis-outage chaos drill a circuit breaker cut p50 latency from 16,377 ms to 2,035 ms (-88%). It ships with Kubernetes manifests and is live at rag.harshgiri.site.
